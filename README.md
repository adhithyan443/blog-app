# 📝 React Firebase Blog App

A modern **Blog Management Application** built with **React**, **Firebase Authentication**, **Cloud Firestore**, and **Tailwind CSS**. Users can securely create an account, log in, publish blogs, edit their own posts, search blogs, and manage their content through a clean and responsive interface.

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/adhithyan443/blog-app.git
```

Move into the project

```bash
cd react-blog-app
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

---

## 🔥 Firebase Setup

Create a Firebase project.

Enable:

- Authentication
- Email/Password Sign In
- Cloud Firestore

Create a `.env` file.

```env
VITE_API_KEY=your_api_key
VITE_AUTH_DOMAIN=your_auth_domain
VITE_PROJECT_ID=your_project_id
VITE_STORAGE_BUCKET=your_storage_bucket
VITE_MESSAGING_SENDER_ID=your_sender_id
VITE_APP_ID=your_app_id
```
